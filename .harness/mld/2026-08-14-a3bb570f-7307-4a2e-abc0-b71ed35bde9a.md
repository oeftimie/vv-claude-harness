## Learnings

- `--plugin-dir <checkout>` + per-project `enabledPlugins: false` is a clean
  harness-of-the-harness rig: toy sessions run the unreleased plugin with zero
  global config changes. Trust (`hasTrustDialogAccepted`) is the one global touch.
- Workflow resume requires resending the ORIGINAL args with
  scriptPath+resumeFromRunId — fails fast otherwise. Found only because a drill
  actually died mid-run.
- Drill timing can be fully scripted: poll the dashboard jsonl for SubagentStop,
  kill, hash, `claude --resume` — no human in the loop, reproducible.
- An organic failure (F003's REVISE round) is stronger drill evidence than
  injected sabotage; record it as such with disclosure rather than re-inducing.
- The 10-minute background-Bash cap is the binding constraint on headless drill
  runs; OS-detached processes + Monitor exit-markers are the pattern that works.
- Review rounds on "docs-only" release branches still find majors (stale
  manifests, dangling cross-references) — the vocabulary/pointer class doesn't
  show up in any diff-adjacent test.
